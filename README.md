# angrydoc-funnels

GitHub Pages site for [angrydocpt.com](https://angrydocpt.com/).

- `/` — Athletic Therapy Center clinic website
- `/funnels/` — condition hub (the former homepage)
- `/sciatica.html`, `/knee-pain.html`, `/pinched-nerve.html`, `/frozen-shoulder.html`, `/scoliosis.html` — condition funnel pages

`build.py` rebuilds the condition pages in place and writes the hub to `funnels/index.html`. It does not overwrite the clinic homepage at the root.
